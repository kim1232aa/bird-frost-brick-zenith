## 4. 调查报告（上游实测，2026-09-14）

### 4.1 fal 视频（探针 + 官方文档，直接可用于实现）

端点探活（`POST https://queue.fal.run/{endpoint}`，空体 200=存在；探针产生的队列请求已全部 cancel，未产生费用）：

| 预设模型 | t2v 端点 | i2v 端点 | 参考图规则 |
|---|---|---|---|
| kling-3-pro | `fal-ai/kling-video/v3/pro/text-to-video` | `.../image-to-video` | `start_image_url` 首帧 + `end_image_url` 尾帧（**最多 2 张**）；duration 3–15s；t2v 有 aspect_ratio 16:9/9:16/1:1、generate_audio、shot_type、negative_prompt、cfg_scale |
| kling-3-turbo | `fal-ai/kling-video/v3/turbo/text-to-video`（探针确认） | `.../v3/turbo/image-to-video`（未探针；官方文档含 `ImageToVideoV3TurboStandardRequest`） | `image_url` **仅首帧 1 张**；duration 3–15s |
| hailuo-2.3 | `fal-ai/minimax/hailuo-2.3/pro/text-to-video` | `.../image-to-video` | `image_url` **仅首帧 1 张**；prompt_optimizer |
| veo-3.1 | `fal-ai/veo3.1/text-to-video` | `fal-ai/veo3.1/image-to-video` | `image_url` **仅首帧 1 张**；aspect_ratio auto/16:9/9:16；duration 4s/6s/8s；resolution 720p/1080p/4k；seed、negative_prompt、generate_audio、safety_tolerance |
| wan-pro | `fal-ai/wan-pro/text-to-video` | `fal-ai/wan-pro/image-to-video` | `image_url` **仅首帧 1 张**；seed、enable_safety_checker；6s 1080p 固定 |
| minimax-h3 | `fal-ai/minimax/hailuo-03/text-to-video` | 未验 | 官方文档标注 early access（未 GA），队列可提交但执行未验证 |

队列协议：submit `POST queue.fal.run/{ep}` → `{request_id}`；状态 `GET queue.fal.run/{ep}/requests/{id}/status`（IN_QUEUE/IN_PROGRESS/COMPLETED/FAILED）；结果 `GET queue.fal.run/{ep}/requests/{id}` → `{video:{url}}`。取消：`PUT .../requests/{id}/cancel`。

**注意**：queue 走 `queue.fal.run`，与 vault baseUrl `fal.run` 不同源——`aee6232` 的同源 hint 需放宽为「同主机或其子域」才能让 fal 适配器复用 baseUrlHint。

### 4.2 HF Inference Router（实测）

- nscale：FLUX.1-schnell t2i ✅（前端已验证）；Z-Image-Turbo、FLUX.2-dev 报 `Model not supported by provider nscale`。
- fal-ai 路径：HF 模型 id 一律路由层拒绝；provider id 直传报 fal 侧 `Application "images" not found`（路由集成坏）。
- wavespeed/replicate：`Not allowed to POST /v1/images/generations`。
- 结论：Z-Image-Turbo（仅 fal-ai/replicate/wavespeed 挂载）与 FLUX.2-dev（全平台仅 i2v 且 OpenAI 兼容端点均不可用）**目前无法经 HF router 出图**，属上游限制，已从 HF 预设移除并在 remark 留档。
- 用户给的第一个 HF key 月度额度耗尽（`depleted monthly included credits`），已按「换 key」切换到备用 key（`local-test-keys.json`，仓库外）。
