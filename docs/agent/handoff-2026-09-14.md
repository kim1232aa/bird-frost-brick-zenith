## 4. 调查报告（上游实测，2026-09-14）

### 4.1 fal 视频（2026-09-15 结果拉取重验，取代 2026-09-14 版）

**方法论警告**：fal 队列 submit 对**任意路径**都回 200 IN_QUEUE（含 bogus 路径），
假端点随后秒回 0.05s「COMPLETED」。2026-09-14 版用 submit 探活因此有两处死端点被误判存活。
唯一可靠的判别是**结果拉取**：submit 非法参数后拉结果——
真端点回参数校验错误（loc/msg）或真实任务；假端点结果 404 `Path /yyy not found`。

| 预设模型 | t2v 端点 | i2v 端点 | 参考图规则 |
|---|---|---|---|
| kling-3-pro | `fal-ai/kling-video/v3/pro/text-to-video` | `.../image-to-video` | `start_image_url` 首帧 + `end_image_url` 尾帧（**最多 2 张**）；duration 3–15s；t2v 有 aspect_ratio 16:9/9:16/1:1、generate_audio、negative_prompt、cfg_scale |
| kling-3-standard | `fal-ai/kling-video/v3/standard/text-to-video` | `.../image-to-video` | 同 pro 合同（首尾 2 张） |
| kling-3-turbo | `fal-ai/kling-video/v3/turbo/standard/text-to-video` | `.../v3/turbo/standard/image-to-video` | `image_url` **仅首帧 1 张**；duration 3–15s；aspect_ratio（仅 t2v） |
| kling-3-turbo-pro | `fal-ai/kling-video/v3/turbo/pro/text-to-video` | `.../v3/turbo/pro/image-to-video` | 同 turbo（仅首帧） |
| hailuo-2.3 | `fal-ai/minimax/hailuo-2.3/pro/text-to-video` | `.../image-to-video` | `image_url` **仅首帧 1 张**；prompt_optimizer |
| veo-3.1 | `fal-ai/veo3.1`（**根路径**；`.../text-to-video` 是假的） | `fal-ai/veo3.1/image-to-video` | `image_url` **仅首帧 1 张**；aspect_ratio auto/16:9/9:16；duration 4s/6s/8s；resolution 720p/1080p/4k；seed、negative_prompt、generate_audio |
| wan-pro | `fal-ai/wan-pro/text-to-video` | `fal-ai/wan-pro/image-to-video` | `image_url` **仅首帧 1 张**；seed、enable_safety_checker；6s 1080p 固定 |
| minimax-h3 | `fal-ai/minimax/hailuo-03/text-to-video` | `.../image-to-video` | `image_url` **仅首帧 1 张**；duration 为**数字 ≤15**；已 GA（非 early access） |

队列协议：submit `POST queue.fal.run/{ep}` → `{request_id}`；状态 `GET queue.fal.run/{app命名空间前两段}/requests/{id}/status`；结果 `GET .../requests/{id}` → `{video:{url}}`。
**状态/结果必须走 app 命名空间（如 `fal-ai/kling-video`），用完整端点路径查状态会 405。**
取消：`PUT .../requests/{id}/cancel`（探针任务全部已 cancel/自然秒结，实测费用仅 kling-3-turbo E2E 数次真实生成）。

relay 侧：`queue.fal.run` 与 vault baseUrl `fal.run` 不同源，同源 hint 已放宽为「同主机或其子域」（`resolveSameOriginBaseOverride`），fal 适配器 createVideo/pollVideo 均带 `baseUrlHint` 走 queue.fal.run；三请求抓包实证密钥只由服务端附加。

### 4.2 HF Inference Router（实测）

- nscale：FLUX.1-schnell t2i ✅（前端已验证）；Z-Image-Turbo、FLUX.2-dev 报 `Model not supported by provider nscale`。
- fal-ai 路径：HF 模型 id 一律路由层拒绝；provider id 直传报 fal 侧 `Application "images" not found`（路由集成坏）。
