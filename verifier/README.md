终验验收标准：
1. `npm test`（node22）885+ 项全过。
2. 每个已配置供应商至少 1 次前端真实点击生成成功并截图（生成图/视频出现在页面且落作品库）。
3. 故事导演：AI 分析→分镜→出图→视频全链路点击通过；分析失败时有可见降级提示。
4. 载荷抽查：Grok 视频多参考模型提交携带 ≥2 张参考图（reference_images list[N>=2]）。
5. 作品库非空，缩略图可渲染。
6. 画布分镜视频节点：选择器/参数卡/实际提交模型一致；无单一模型名误导标题。
7. 审计发现的 API 参数缺口、空壳、误拦：修复或给出明确结论。
